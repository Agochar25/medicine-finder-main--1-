# 💊 MediFind - Medicine Availability & Nearby Pharmacy Finder

A full-stack web application that helps people find medicines and nearby pharmacies with live stock availability.

## 🚀 Features
- 🔍 Medicine Search
- 🏪 Nearby Pharmacy Finder
- 📦 Live Stock Updates
- 🚨 Emergency Medicine Request
- 📍 Location-based Results

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Real-time: Socket.io

## ⚙️ Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/Agochar25/medicine-finder-main--1-.git

2. Install dependencies
   cd backend
   npm install

3. Start MongoDB
   brew services start mongodb-community

4. Run the server
   node server.js

5. Open the app at http://localhost:3000
